# runs/ 实测与评分

## 结构

- `data/<题号>/` —— 原始回答（机器产物），按题目分目录。每题每家一对文件：
  `.json`（结构化，含 system_prompt 快照）+ `.md`（可读版）。
  回答一字不改，包括语气词和错别字，这是公信力的来源。
  `.broken` 后缀 = 该次运行不完整（如 API 返回为空），仅存档，不参与评分。
- `scores/r1-初评/` —— 第一遍评分：AI（Kimi 族）预打分 + 鹿小苗裁定（16 个分歧点记录在案）
- `scores/r2-deepseek/` —— 第二遍评分：DeepSeek 用同一 rubric 盲评（`python run_scoring.py` 生成），
  用于双评分者一致率检验
- `scores/leaderboard.md` —— 总榜（基于 r1 定稿）

## 文件命名

`题号_模型_日期`，例如 `RP-001_deepseek_20260821.md`

## 规则

- 同时保留截图（放 `data/screenshots/`），防篡改质疑
- 模型如果拒绝角色扮演或跳出人设，原样记录，这本身就是数据
- 评分前先做数据完整性检查（空回答、缺轮次），见 RP-003 豆包 0822 案例
