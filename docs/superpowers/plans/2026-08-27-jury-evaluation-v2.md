# 评审团机制（V2 计划，暂缓执行）

> 状态：**封存待做**（2026-08-27 鹿小苗决定：先发布 V1，评审团方案排期 V2）。
> 触发背景：发现 AI 预打分模型与参评模型 Kimi 同族（ccswitch 接入），存在利益冲突。

## 问题

V1 的评分链是"Kimi 族模型起草 rubric + 预打分 → 鹿小苗裁定"。两个利益冲突点：
标准制定者与选手同族；评分者与选手同族。鹿小苗裁定环节存在锚定效应
（先看到 AI 建议再裁定，同意率天然偏高）。

## V2 设计：多评审团 + 人类终审

1. **四家参评模型全部担任评审**，用同一份冻结版 rubric，对全部匿名回答盲评
   （包括评自己——盲评下自评无妨）。偏见相互抵消，分歧暴露给人。
2. **匿名化**：评审输入剥离模型名，只给题面 + 对话内容。
3. **聚合**：每题每维度取多数票/中位数；计算评审间一致率
   （exact agreement %，可选 Cohen's kappa）。
4. **人类终审**：一致率 < 100% 的条目全部进鹿小苗裁定队列。
   人是终审法院，不是初审法官。
5. **标准对立审查**：把 rubric 喂给对立模型，任务="找出这份标准里
   有利于特定文风的条款"。

## 已就绪的工程

- `run_scoring.py`：盲评脚本，`--judge <模型>` 切换评审，输出到
  `runs/scores/r2-<模型名>/`，已去重跳过已评条目

- 目录结构：`runs/scores/r1-初评/`（V1 定稿）+ `r2-<模型>/`（各评审产出）

## rubric 对立审查提示词（备用）

> 你是评测标准的对抗审查员。下面是一份"情感智能评测"的评分细则。
> 你的任务是找出其中所有可能偏向特定回答风格的条款：
> 哪些描述天然奖励"话少克制型"回答？哪些惩罚"长篇热情型"回答？
> 哪些标准只有某种训练偏好的模型才能满足？逐条列出并给出理由。
