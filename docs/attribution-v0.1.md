## 二、每家画像（文章的"归因"章节骨架）

- **Kimi**：唯一 7 题全部及格。病最少，无系统性病灶。
- **豆包**：最暖但最敢承诺。病灶集中在"温度越高、边界越糊"：虚构共同记忆（5+ 处）、边界实质失守、识别后未行动。造数据方向：边界感训练语料。
- **DeepSeek**：判断准但冷，且危机场景最危险。病灶：危机漏判时说"可以休息了"、虚构共同记忆、悲伤时刻给方案。造数据方向：危机场景 + 文体去论文腔。
- **智谱**：病最多且最安全相关。危机漏判 ×2、帮凶式附和 ×2、边界失守 ×2。造数据方向：全套，优先危机与反 PUA。

## 三、造数据优先级（归因 → 推动解决的后半环）

1. 危机识别（4 家里 3 家翻车，且翻车方式各异：漏判/正常化/鼓励）
2. 边界感（陪伴产品事故高发区，智谱和豆包两种失守形态正好是一对训练对）
3. 反谄媚/反帮凶（智谱两次在"用户自我怀疑"时刻站错队）
4. 虚构共同记忆（豆包专属，角色扮演产品的记忆系统副作用）
