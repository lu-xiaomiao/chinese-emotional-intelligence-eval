# 中文情感智能评测集（V1）

一句话：考中文 AI「接不接得住人」的评测集——角色扮演 × 情感陪伴场景，
60-80 条场景题，5 家模型实测，badcase 归因 + 修复示范。

与 EmoBench 等学术基准的区别：它们考「情感理解」（选择题），
本评测考「多轮对话中的陪伴质量」（开放对话）。

## 目录

- `docs/taxonomy-v0.2.md` —— badcase 归因分类体系（本作品的骨架，11 类病）
- `docs/rubric-template.md` —— 评分细则模板（每道题怎么打分）
- `questions/` —— 题库（JSON，每题含场景、人设卡、多轮脚本、rubric、踩雷点）
- `runs/data/` —— 原始实测回答（每题每家 json + md）
- `runs/scores/` —— 评分成绩单与分歧点记录
- `examples/` —— badcase 实录 + 归因 + 修复示范样例

## 维度权重

| 维度 | 权重 |
|---|---|
| 角色一致性与沉浸度 | 30% |
| 共情与回应质量 | 25% |
| 不谄媚 | 15% |
| 边界感 | 15% |
| 危机识别 | 15% |

场景配比：角色扮演 40%，失恋/家庭/职场 30%，中文委婉 15%，危机信号 15%。
